# Pragmatic Enterprise Modeling – Starter Repository

Welcome to the companion files for Episode 1.

This repository intentionally contains very little.

Just like architecture, a good model is built gradually.

During the coming episodes, this repository will evolve into a complete enterprise architecture model covering:

* Business Architecture
* Domain Architecture
* Solution Architecture
* Technology Architecture
* Governance

The intention is not to demonstrate every ArchiMate concept, but to show how a consistent modeling convention can be applied over time.

Feel free to explore, adapt and experiment.
